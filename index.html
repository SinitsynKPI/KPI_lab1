Тестування та опис UI-компонентів

1. Radiobutton (Радіокнопка)

Призначення: Дозволяє обрати лише один варіант із декількох взаємовиключних опцій.


2. Checkbox (Прапорець)

Призначення: Дозволяє обрати один або кілька незалежних параметрів.


3. Text input (Поле введення тексту)

Призначення: Поле для введення однорядкового тексту користувачем.

4. Tabs (Вкладки)

Призначення: Дозволяють розділити вміст на кілька перемиканих областей в межах одного вікна.

Вміст першої вкладки.
Вміст другої вкладки.

5. Button (Кнопка)

Призначення: Ініціює виконання певної дії чи події при натисканні.

6. Text label (Текстова мітка)

Призначення: Поповнює інтерфейс текстовим описом або назвою для іншого елемента.

7. Link (Посилання)

Призначення: Дозволяє здійснювати перехід на іншу сторінку або веб-ресурс.

Перейти на GitHub

8. Tooltip (Вспливаюча підказка)

Призначення: Відображає коротку контекстну підказку при наведенні миші.

Наведіть курсор сюди Це підказка (Tooltip)!

9. Dropdown list (Випадаючий список)

Призначення: Дозволяє обрати один варіант із випадного списку опцій.

10. Data grid (Таблиця даних)

Призначення: Відображає структуровані дані у вигляді таблиці з колонками та рядками.
